# SkyFall

**Live: https://skyfall.keyurib.workers.dev**

Day 2 of [100 Days](https://100days.keyurib.workers.dev): a cinematic, interactive WebGPU hero for a Mars mission concept. Three autonomous helicopters are released mid-air during descent and scan Mars for subsurface ice.

> Conceptual mission visualization. It does not show live mission data.

## What it does

- **Procedural Mars in WebGPU:** regolith, craters, a canyon system and polar caps baked on the GPU; a thin butterscotch atmosphere; restrained bloom (sun and radar pulse only).
- **Intro:** a 10-second camera dolly, an entry-vehicle streak, and three helicopters that separate and fan out, then hover as dark silhouettes with a subtle warm rim.
- **Radar scan:** a sweep crosses the planet and reveals possible subsurface ice (about 0.5–3 m deep) with a blue-white glow, contour lines and a survey grid. "Initiate radar scan" runs it again.
- **Interactive:** drag to turn Mars; click the surface for a radar ping with a readout; four hotspots (Arrival, Helicopters, Terrain, Subsurface ice) open short info cards. "Explore Mars" reveals them.
- **Accessible:** keyboard reachable (Tab, Enter, Esc), announced results, contrast of 4.5:1 or better, and `prefers-reduced-motion` respected (no flight, dolly or sweep).
- **Fallback:** without WebGPU, a matching static poster over a starfield, with the same hotspots and cards.

## Stack

Next.js 16 (static export) · React 19 · TypeScript · [vgpu](https://www.npmjs.com/package/vgpu) 0.6 · WGSL · Cloudflare Workers (static assets)

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # static export to out/
npm run deploy       # build + wrangler deploy
```

## Verify it

Every visual claim is checked against real pixels, not just compiled:

```bash
npm run check:wgsl          # every shader through `vgpu check` (validated by Naga)
npm run typecheck
npm run doctor              # vgpu environment health (WebGPU adapter)
npm run render:m1a          # headless renders (vgpu/node) with pixel assertions:
npm run render:m1b          #   surface, atmosphere + bloom,
npm run render:m2           #   intro timeline,
npm run render:m3           #   radar + ice reveal,
npm run render:interaction  #   picking, drag, parallax, ping, full-bleed framing
npm run render:posters      # regenerate the fallback posters and starfield
npm run build && npm run test:browser   # Playwright in Chrome against the static export
```

## Project files

- `src/` — the hero: `MarsHero.tsx` (stage, hotspots, cards), `SkyfallHero.tsx` (copy and CTAs), `renderer.ts` (WebGPU lifecycle and input), `animation.ts` (deterministic timeline), `hud.ts` (projection and picking), `mars-scene.ts` (render passes), `shaders/` (WGSL).
- `scripts/` — headless renders, poster generation, the browser test.
- `AGENT.md`, `DESIGN.md`, `MISSION_FACTS.md`, `implementation.md`, `acceptance-tests.md` — the original brief. The reference images it mentions (`references/`) are not included in this repository.
